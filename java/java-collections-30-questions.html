📦 Top 30 Java Collections Questions

SDET / Automation QA interview prep — List, Set, Map, Queue & Comparators

1ArrayList vs LinkedList — when to use which

ArrayList gives O(1) random access but O(n) inserts/removes in the middle. LinkedList gives O(1) insert/remove at the ends but O(n) access. Use ArrayList for frequent reads, LinkedList for frequent insert/delete.

List arrList = new ArrayList<>();
List linkedList = new LinkedList<>();
arrList.add(10);
linkedList.addFirst(5);

2Remove duplicates from a List

Wrap the list in a LinkedHashSet to drop duplicates while preserving insertion order.

static List removeDuplicates(List list) {
    return new ArrayList<>(new LinkedHashSet<>(list));
}

3Iterate and remove elements safely

Modifying a list while using a for-each loop throws ConcurrentModificationException. Use an Iterator's remove() instead.

Iterator it = list.iterator();
while (it.hasNext()) {
    int n = it.next();
    if (n % 2 == 0) it.remove();
}

4Sort a List of custom objects by one field

Comparator.comparing extracts the field to compare on — no need to write a full Comparator class.

List emps = getEmployees();
emps.sort(Comparator.comparing(Employee::getName));

5Sort by multiple fields

Chain thenComparing to break ties using a second field.

emps.sort(
    Comparator.comparing(Employee::getDept)
              .thenComparing(Employee::getSalary, Comparator.reverseOrder())
);

6HashMap vs TreeMap vs LinkedHashMap

HashMap gives no ordering guarantee, LinkedHashMap keeps insertion order, TreeMap keeps keys sorted. Pick based on whether order matters.

Map hash = new HashMap<>();
Map linked = new LinkedHashMap<>();
Map tree = new TreeMap<>();

7Iterate over a Map's entries

entrySet() avoids a second lookup per key, unlike calling map.get(key) inside a keySet() loop.

for (Map.Entry e : map.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}

8Sort a HashMap by value

Convert the entrySet to a List, then sort with a Comparator on the value.

static List> sortByValue(Map map) {
    List> list = new ArrayList<>(map.entrySet());
    list.sort(Map.Entry.comparingByValue());
    return list;
}

9Count word frequency using a Map

merge() increments the count if the key exists, or inserts it with a default if not.

static Map wordFrequency(String[] words) {
    Map freq = new HashMap<>();
    for (String w : words) freq.merge(w, 1, Integer::sum);
    return freq;
}

10Check if a key exists before accessing it

containsKey() avoids a NullPointerException from an unguarded get() call.

if (map.containsKey("status")) {
    String status = map.get("status");
}
// or safer:
String status = map.getOrDefault("status", "UNKNOWN");

11Group elements using groupingBy

Streams' Collectors.groupingBy buckets elements by a classifier function into a Map.

Map> byDept =
    emps.stream().collect(Collectors.groupingBy(Employee::getDept));

12Find duplicate elements in a List using Streams

Group by identity and keep only the keys whose group size is greater than 1.

Set duplicates = list.stream()
    .collect(Collectors.groupingBy(x -> x, Collectors.counting()))
    .entrySet().stream()
    .filter(e -> e.getValue() > 1)
    .map(Map.Entry::getKey)
    .collect(Collectors.toSet());

13Convert a List to an array and back

toArray() needs a typed array argument to return the correct type; Arrays.asList() wraps an array as a fixed-size List.

List list = Arrays.asList("a", "b", "c");
String[] arr = list.toArray(new String[0]);
List backToList = new ArrayList<>(Arrays.asList(arr));

14Find the intersection of two Lists

retainAll() keeps only elements present in both — mutate a copy so the originals stay untouched.

static List intersection(List a, List b) {
    List result = new ArrayList<>(a);
    result.retainAll(b);
    return result;
}

15Find the difference between two Lists

removeAll() strips out anything present in the second list.

static List difference(List a, List b) {
    List result = new ArrayList<>(a);
    result.removeAll(b);
    return result;
}

16Make a List immutable

List.of() and Collections.unmodifiableList() both block structural changes — the second wraps an existing list.

List immutable = List.of(1, 2, 3);
List wrapped = Collections.unmodifiableList(new ArrayList<>(list));

17Thread-safe collection options

Collections.synchronizedList wraps with a lock on every call; ConcurrentHashMap and CopyOnWriteArrayList use finer-grained concurrency and scale better under contention.

List syncList = Collections.synchronizedList(new ArrayList<>());
Map concurrentMap = new ConcurrentHashMap<>();
List cowList = new CopyOnWriteArrayList<>();

18Implement a custom Comparator class

Override compare() to define the ordering logic explicitly, useful when the logic is reused across multiple sorts.

class SalaryComparator implements Comparator {
    public int compare(Employee a, Employee b) {
        return Double.compare(a.getSalary(), b.getSalary());
    }
}
emps.sort(new SalaryComparator());

19PriorityQueue basics — Min-Heap and Max-Heap

PriorityQueue is a min-heap by default; pass Collections.reverseOrder() to flip it into a max-heap.

Queue minHeap = new PriorityQueue<>();
Queue maxHeap = new PriorityQueue<>(Collections.reverseOrder());
minHeap.add(5); minHeap.add(1); minHeap.add(3);
System.out.println(minHeap.poll()); // 1

20Implement a Stack using Deque

ArrayDeque is the recommended stack implementation — faster than the legacy Stack class.

Deque stack = new ArrayDeque<>();
stack.push(1);
stack.push(2);
System.out.println(stack.pop()); // 2

21Implement a Queue using Deque

Deque works as a FIFO queue too — offer at the tail, poll from the head.

Deque queue = new ArrayDeque<>();
queue.offer(1);
queue.offer(2);
System.out.println(queue.poll()); // 1

22Find the max/min element in a List

Collections.max/min take a Comparator, so they work directly on custom objects too.

int max = Collections.max(list);
int min = Collections.min(list);
Employee highestPaid = Collections.max(emps, Comparator.comparing(Employee::getSalary));

23Convert a List of objects into a Map

Collectors.toMap needs a key function and a value function — watch out for duplicate keys, which throw by default.

Map idToName = emps.stream()
    .collect(Collectors.toMap(Employee::getId, Employee::getName));

24Merge two Maps

putAll() overwrites shared keys with the second map's values; merge() lets you control conflict resolution.

Map merged = new HashMap<>(map1);
map2.forEach((k, v) -> merged.merge(k, v, Integer::sum));

25Find the top N elements from a List

Sort in reverse order (or use a bounded min-heap) and take the first N.

List topN = list.stream()
    .sorted(Comparator.reverseOrder())
    .limit(3)
    .collect(Collectors.toList());

26Partition a List into two groups

Collectors.partitioningBy splits into exactly two buckets based on a boolean predicate.

Map> partitioned = list.stream()
    .collect(Collectors.partitioningBy(n -> n % 2 == 0));
List evens = partitioned.get(true);
List odds = partitioned.get(false);

27Flatten a List of Lists

flatMap turns each inner list into a stream, then merges all of them into one.

List> nested = getNestedList();
List flat = nested.stream()
    .flatMap(List::stream)
    .collect(Collectors.toList());

28TreeSet — sorted unique elements

TreeSet keeps elements sorted automatically and rejects duplicates, backed by a Red-Black tree.

TreeSet sortedSet = new TreeSet<>(List.of(5, 1, 4, 2));
System.out.println(sortedSet.first()); // 1
System.out.println(sortedSet.last());  // 5

29Check if a Collection is empty safely

isEmpty() is clearer and slightly faster than checking size() == 0, and works even if the reference could be null with an extra check.

if (list == null || list.isEmpty()) {
    System.out.println("No data");
}

30Deep copy vs shallow copy of a List

A `new ArrayList<>(list)` copies references only (shallow) — mutating an object inside affects both lists. A deep copy clones each element individually.

List shallow = new ArrayList<>(originalList);
List deep = originalList.stream()
    .map(Employee::new) // assumes a copy constructor
    .collect(Collectors.toList());
